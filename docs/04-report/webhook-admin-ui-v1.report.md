## 5. Decisions Made During the Cycle

1. **streamlit-free 테스트 격리** — `dashboard/components/__init__.py`가 다른 모듈을 eager import해 streamlit 미설치 환경에서 테스트가 깨졌음. `importlib.util.spec_from_file_location`로 webhook_admin 서브패키지의 순수 모듈만 직접 로드해 우회. 결과적으로 "formatters/api_client는 streamlit 없이 임포트 가능해야 한다"는 경계가 테스트로 강제됨.
2. **secret 1회 노출 정책** — `st.session_state[_webhook_last_secret]`에만 보관, ack 버튼으로 즉시 `pop`. `st.cache_*` 미사용, 로그 호출 0.
3. **retry 버튼 sprawl cap** — failed/dead delivery가 수십~수백 건일 수 있어 상위 10건만 버튼 표시. v2에서 일괄 retry로 해결 권장.
4. **dataframe + selectbox 분리** — Streamlit dataframe row-click 미지원에 대한 실용적 선택. 설계의 "선택 시 webhook_id 반환" 계약은 정확히 지킴.
5. **이벤트 카탈로그 캐시** — `@st.cache_resource(ttl=60)` (거의 변하지 않음). 캐시 함수 내부에서 client 생성/즉시 close — 캐시 객체는 `list[dict]`만 유지.
6. **에러 토스트 통일** — 모든 view 함수가 `WebhookAdminError`만 잡고 `toast_error(str(e))`로 노출. 백엔드 detail 메시지를 그대로 사용자에게 노출 (백엔드 검증 메시지 재사용).
